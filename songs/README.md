# songs

練習アプリで使う曲のデータ置き場です。**中身はすべて合言葉で暗号化**してあり、合言葉がないと読めません。
暗号化する前の元データは `プライベート用/鼓笛隊/曲データ/` にあります（公開しない）。曲の追加方法もそちらの README を見てください。

## 📁 フォルダの中身

| ファイル | 内容 |
|---|---|
| [README.md](README.md) | このファイル。フォルダの案内 |
| [songs.enc](songs.enc) | 曲の一覧（暗号化済み） |
| [kirakira.enc](kirakira.enc) | お試し曲「きらきら星」（暗号化済み） |
