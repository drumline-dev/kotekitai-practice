# 練習アプリ（試作）

鼓笛隊の子どもが、家でスマホを使って曲の練習をするための Web アプリです。
楽譜を再生すると、五線譜の上で今の位置が示され、押す鍵盤がオレンジ色に光ります。

## ✅ できること（試作の時点）

| 機能 | 内容 |
|---|---|
| 合言葉 | 合言葉を入れないと使えない（1度入れたらその端末では次から不要）。曲データは合言葉で暗号化してあり、ファイルを直接取り出しても読めない |
| 曲えらび | 曲の一覧が並ぶ。`?song=曲のID` 付きの URL なら直接その曲が開く |
| 五線譜 | 自分のパートの楽譜だけを表示し、今弾いている所に緑のカーソルが出る |
| 音楽記号 | 練習記号（A・B…）、テンポ、強弱（mf・f など）、クレシェンド、コーダ・セーニョ、rit.、フェルマータなど、楽譜に入っている記号を表示する |
| 演奏を始める場所 | 「最初から」「Bから」「Cから」「コーダから」などを選べる（楽譜の練習記号・コーダ・セーニョから自動で作る） |
| 鍵盤 | 今おす鍵盤がオレンジに光る（予告はなし）。和音は複数の鍵盤が光る。最低2オクターブ表示 |
| 打楽器パッド | 打楽器のパートを選ぶと、画面の配置が打楽器用に変わる（ボタンは左に縦ならび、楽譜は1段の帯で演奏に合わせて横に流れる、パート・始める場所の選択は「せってい」の中）。上から見た本物っぽい太鼓の絵（白いヘッド・銀色のフープ・金具、シンバルは金色）が大きく出る。太鼓の外やすき間をタップしても、一番近い太鼓を叩いたことになる。叩くタイミングで光る（予告はなし）。アクセントは赤く光って「＞」、リムショットはフープ（外側の銀色の輪）が光る。タップで音が出て、再生中は合っていれば緑、ずれていれば赤の枠（前後0.15秒以内なら合格）。テナードラムは奥に弧の形で 5・3・2・4（左→右）、中央の手前に 1・1 を置き、音程は 1:ミ 2:ド 3:ラ 4:ファ 5:レ。そのほかの複数の太鼓はパッドを横にならべる |
| 鍵盤を押す | 画面の鍵盤をタッチすると音が出る。複数の指で同時に押せる。再生中は合っていれば緑、ちがえば赤の枠が出る |
| 鳴らす音 | 「お手本（自分のパートだけ）」「全体の演奏」「伴奏だけ」から選べる |
| メトロノーム | 鳴らす・鳴らさないを選べる |
| はやさ | BPM（♩= いくつ）で 30〜240 の間で設定。最初は楽譜のはやさ。「（楽譜 100）」を押すと元にもどる |
| くり返し | 「○小節目から○小節目まで」をくり返す（小節の一覧に A・B などの記号も出る） |
| その他 | ドレミ表示の切りかえ、楽譜の大きさ変更、縦向きのときは「横向きにしてね」と表示、再生中は画面が暗くならない（対応端末のみ） |

## ⚠️ まだできないこと・注意

- 記号は**表示するだけ**で、演奏の順番には反映していない。**リピート記号・D.S.・To Coda・1番カッコ／2番カッコ**があっても、楽譜を頭から順に演奏する。実際の楽譜で必要か確認して対応予定
- 曲の途中でテンポが変わっても、最初のテンポのまま演奏する
- ファイフのパートを選ぶと、楽譜と鍵盤が出る（運指の画面はあとで作る）
- 打楽器のロール（トレモロ）は1回叩く音として扱う。手順（R・L）は表示しない
- 太鼓の区別は楽譜の「楽器名」または「五線上の位置」で行う。テナーの番号は楽器名の数字（例：テナー3）、なければ五線の高い位置から 1・2・3… とする（6個なら上の2つが 1・1）。リムショットは楽器名に「リム」などが入っているか、× の形の音符で判定する
- 音はアプリが作った「それっぽい音」で、本物の楽器の録音ではない
- **iPhone はマナーモード（消音スイッチ）だと音が出ない**ことがある → 保護者への案内に書く
- 合言葉は「かんたんな鍵」。URL と合言葉を知っている人は使えるので、合言葉を団体の外に広めないようにする
- 楽譜の表示には外部の部品（OpenSheetMusicDisplay）をインターネットから読み込んでいるため、通信が必要

## 🎼 新しい曲を追加する手順（先生用）

1. 紙の楽譜を PDF・写真にする
2. パソコンの楽譜ソフトで読み取る
   - **MuseScore Studio**（無料）：「ファイル → 読み込み」で PDF を読み込む（PDF の読み取りは MuseScore のオンライン機能を使う）
   - **Audiveris**（無料）：PDF を読み取って MusicXML を書き出せる
3. 読み取りの間違いを直す。パート名は分かりやすく（例：「鍵盤ハーモニカ」「ファイフ」「スネア」）
   - パート名に「鍵盤」「ハーモニカ」が入っていると、最初からそのパートが選ばれる
   - パート名で音色が決まる（「笛・ファイフ」→ 笛の音、「スネア」「バスドラ」「シンバル」「テナー」→ それぞれの打楽器の音）
   - 練習記号（A・B…）は、MuseScore の「リハーサルマーク」で入れると「演奏を始める場所」に出る
4. **非圧縮の MusicXML（拡張子 `.musicxml`）** で書き出す（`.mxl` は不可）
5. `プライベート用/鼓笛隊/曲データ/` に入れて暗号化する（手順はそのフォルダの README.md）

## 💻 パソコンで動かして確認する方法

このフォルダで次を実行し、ブラウザで `http://localhost:8765/` を開く。

```powershell
python -m http.server 8765 --directory .
```

> ファイルを直接ダブルクリックで開くと、曲の読み込みや合言葉の確認が動きません。
> 同じ理由で、パソコンの IP アドレス（`http://192.168.…`）をスマホで開いても使えません。スマホでは公開後の https の URL で開いてください。
